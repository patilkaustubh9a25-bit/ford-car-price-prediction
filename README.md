# Ford Car Price Prediction

## Project Overview

This project explores Ford used-car data and applies machine learning techniques to predict car prices using Python.

## Objectives

* Explore and understand the dataset.
* Perform exploratory data analysis (EDA).
* Visualize relationships between car features and prices.
* Apply categorical encoding and feature scaling.
* Build and evaluate Linear Regression models.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning

The project experiments with Linear Regression using two categorical encoding approaches:

* One-Hot Encoding
* Label Encoding

The models are evaluated using R² and adjusted R² scores.

## Results

The One-Hot Encoding approach achieved an R² score of approximately 0.8397 on the saved test split.

The Label Encoding approach achieved an R² score of approximately 0.7310.

These results are from the notebook's saved outputs and have not been independently reproduced.

## Project Structure

* `Ford_Car_Price_Prediction.ipynb` — Data analysis, visualizations, preprocessing, and model evaluation.
* `ford.csv` — Dataset, if included and permitted for redistribution.

## How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Ensure the dataset is available at the path expected by the notebook.
5. Run the notebook cells in order.

## Disclaimer

This project is for educational purposes. Model predictions are estimates and may not reflect actual market prices.
